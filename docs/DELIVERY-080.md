## 这一轮完成的产品行为

### 紧急提示

TaskCard 显示醒目文本徽标：紧急/高优先级、1 小时内截止、已逾期及相对时长；截止另显示具体日期时刻或当天结束。
事件也显示高优先级。首页先展示优先处理，再展示其他当日日程。高优先级事件不会重复出现，也不混进任务完成分母。
时间表高优先级标题带感叹号和红色文字，卡片仍使用中性背景，不恢复整圈红色描边。
提醒内容区分日程开始、截止、指定时刻与提前量；紧急事项系统通知标题带【紧急】。
卡片明确显示未启用、已登记、登记失败、状态未确认。登记失败不回滚任务；不绕过设备勿扰设置。

### 功能开关与工具

设置 → 功能与工具。简洁/完整预设及独立开关：专注、习惯、倒数日、智能输入。
底部四栏保持今天、待办、日历、设置。工具有独立子页，不增加第五个底栏。
隐藏只影响入口，不删除数据，不自动结束既有计时或取消逻辑提醒。重新启用可以看到原记录。
默认新增工具关闭，智能输入开启。用户原来已保存的偏好继续读取。

### 专注

- 可选关联任务；任务被删除后历史保留标题，不自动完成任务。
- 开始、暂停、继续、结束、完成与历史删除；工作/短休/长休与循环设置。
- 工作时长预设 25/45/60 分钟；短休 5/10、长休 15/30、2/4 轮后长休。
- 运行时剩余时间 = 目标秒数 - 已累计秒数 - 本段实际时差，后台/退出后可恢复。
- 暂停段不计有效时长；统计实际有效专注，最多累计到目标时长。
- 系统时间倒退时新增时长钳制为 0，恢复基准不倒退；前拨会影响墙上时钟计时，界面已说明。
- 专注到时逻辑意图接入 ReminderService，系统登记失败时不宣称后台响铃可用。
- 备份正在运行的计时会结算到导出时刻，副本以暂停状态恢复，源计时继续运行。

### 习惯

- 每日、指定星期、每周完成天数目标；每天 1～10 次。
- 每个习惯/日期只有一条计数记录，连点不会超过目标。
- 选择历史日期补打、撤销一次、删除及近期记录。
- 连续统计按应打卡日期计算；非要求日期不打断连续。每周目标按完成天数计算，不按点击次数。
- 创建时确定规则与开始日期；现阶段规则固定，避免修改历史统计含义，需新建变更后的习惯。
- 可切换 08:00/12:00/20:00 提醒或关闭，完成当天目标后不生成当天意图。

### 倒数日与纪念日

- 创建、编辑、删除、最近一次删除撤销、置顶、分类、日期排序。
- 支持未来倒数、过去累计、今天 0 天；公历日期差，不使用毫秒除 24 小时冒充本地日差。
- 每年重复，2 月 29 日在平年按 2 月 28 日，界面明确说明。
- 提前 0/1/3/7 天 09:00 提醒或关闭，逻辑意图复用系统提醒对账。
- 农历未支持。

### 分类、排程与输入

- 清单/标签统一重命名、合并、从任务移除；包含单次例外，任务与完成历史保留，事务执行。
- 日历拖动吸附设置实际传到时间表，支持 5/15/30 分钟。
- 辅助排程可设置工作开始/结束时段，保留固定事件、截止、优先级、预计时长。
- 可采用单条或整批，采用前检查源数据快照；最近一次可撤销。
- 当前排程仍是确定性本地算法，不是云端 AI 自动规划。
- 云端草稿 schema 扩展 kind、list、deadlineDate/Time、repeat、interval、weekdays、until/count、reminder/leadMinutes。
- 字段由 TaskService/PlanningService 再验证；非法日期、时间、规则、提醒组合拒绝。
- 单条打开编辑器时完整传递上述字段；增加固定测试句连接测试，不保存测试任务。
- 识别时收起键盘，输入框同值回调不会清空草稿。原文仍可编辑，确认前不写任务。
- 仅支持兼容 HTTPS Chat Completions 服务；真实凭据端到端请求未验收。

### 备份与设置

- 格式 7，兼容格式 3/4/5/6。
- 包含任务、例外、完成与步骤记录、专注、习惯、倒数日、模块偏好、工作时段、显示/排序偏好、AI 地址与模型。
- 显示偏好改为 SQLite metadata；旧 Preferences 作为读取回退，保留已有用户选择。
- 工具与任务恢复在同一 SQLite 事务内；中途失败整体回滚。
- 同 ID 数据保留本机版本，只合并新 ID；预览说明偏好将恢复。
- 导入中的进行计时恢复为暂停；本机已存在活动计时时，新导入活动记录转为结束，不悄悄启动第二个计时。
- AI 密钥、安全资产、系统提醒 ID/journal 不导出。恢复后当前设备重新对账登记。
- AI 配置迁到 SQLite，仅允许无内嵌凭据、无查询参数的 HTTPS 地址；备份解析丢弃配置里非允许字段。

### ICS 边界修复

EXDATE 和 RECURRENCE-ID 必须匹配主事件原始起始时刻及 DATE/DATE-TIME 类型，不能只按日期错误取消另一时刻。
DTSTART 与 BYDAY 不一致的规则明确拒绝，避免静默丢失首个发生项。
原有常见重复、排除日期、调课、取消和未来 30 天快照导出保留。

## 性能测量

运行 DevEco Node 24：node tools/performance.cjs。
合成 5000 个任务、500 个每周系列，5 次测量。本机纯业务中位数：搜索 1.30 ms、今日概览 29.58 ms、日时间块 6.13 ms、月数据 127.42 ms。
这是 Windows Node 服务计算，不是模拟器帧率。首页对同一任务/状态/当前时刻缓存概览，避免一帧重复计算多个相同统计。
原生大字体、横屏、实际 5000 条长列表滚动、读屏与跨设备帧率仍未全量验收。

## 交付与启动

1. 保持 DevEco 的 API 26 模拟器运行。
2. 在桌面项目双击 Start-TaiPlan.cmd，或 PowerShell 执行 tools/run-emulator.ps1。
3. 新环境构建用 tools/run-emulator.ps1 -Build -DevEcoHome '实际安装路径' -Device '实际设备ID'。
4. 脚本覆盖安装，不卸载应用、不清用户数据；目标设备缺失会明确停止并提示开启模拟器。
   源码比安装包新时会停止并要求重新构建，避免误装历史二进制。
5. 这是原生应用，没有 localhost 访问地址。本机设备 ID 当前为 127.0.0.1:5555。
6. 未签名 HAP 仅在本机模拟器验收，不保证任意真机直接安装。

交付目录 delivery：HAP、源码 ZIP、README/交付说明、汇报 PDF、静音模拟器演示、SHA256 MANIFEST。
源码中保留报告生成脚本；PDF 用系统中文字体生成并渲染核对。
演示视频为原生截图按实际采集时间编码，约 1 fps 采样、12 fps 播放编码，静音、无麦克风录音；不能据此判断动画帧率。
视频时长 3 分 0.67 秒，记录本轮工具和日历操作；录制后补的键盘收起修复另有最终截图证据，视频不作为这项修复的验收证据。

## 未验收及仍保留的产品边界

1. 真机语音识别、锁屏/退进程/重启后通知、真实 AI 请求：按用户选择列为未验收。模拟器提醒发布 1700002，任务保存不受影响。
2. 系统提醒未来 7 天、应用最多 50 条；系统实际配额可能更少。长时间不打开不会自动续约。
3. ICS RDATE/复杂 RRULE/任意时区/DST/同 UID 来源更新尚未完整实现；不能把未知语义降成单次后说“成功”。
4. 未来已有完成记录/例外的复杂系列拆分保留保护拒绝；整系列改变历史锚点和规则不能任意迁移。
5. 云端 AI 排程、多 provider 协议、草稿卡片原位逐字段编辑、日历拖动边缘自动滚动尚未完整实现。
6. 完整无障碍、横屏/大字体/平板、跨时区与真实长列表性能待专项验证。
7. 工具模型当前保存在一个经校验的 SQLite JSON 文档；大量习惯历史需关注 4 MB 备份限制。

这些边界不应被写成“全计划全部完成”。当前交付候选覆盖考核主流程与多个增强模块；正式全产品 1.0 需继续通过相应专项退出条件。
