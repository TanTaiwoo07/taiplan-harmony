## 0.6 这轮增加的行为

### 重复发生项与编辑范围

1. `OccurrenceService` 使用 taskId + originalDate 作为不变身份；TaskItem.dateKey 保持原始日期，TaskItem.dueAt 是实际安排日期。
2. `Task.overrides` 存单次完整草稿、原日期和更新时间。改期后原日期不再出现该次，新日期出现；完成、跳过仍关联原日期。
3. 数据库新增 occurrence_overrides 表，按系列存 JSON。写入、整系列删除、删除撤销和备份恢复覆盖这个表。
4. 卡片及时间块编辑弹出“仅这一次／这次及以后／整个系列”。单次编辑不会修改系列规则。
5. “这次及以后”在同一事务中终止旧系列、创建新系列，保留过去完成记录，有限次数按已使用次数扣减。
6. 有未来完成／跳过或单次例外时，拆分会拒绝并保留原数据；首个发生项要求整系列编辑。
7. 整系列已有历史时仍禁止改变锚点或重复规则；已有单次例外保留独立内容。尚不是任意规则修改都能自动迁移历史的最终实现。

### 日历操作

- 长按时间块后拖动：15 分钟吸附；周视图横向位移按日列转换。
- 区块底部手柄改变时长，确认前展示新时间及冲突提示；短于 30 分钟的块通过编辑器改时长。
- 对重复事项只调整本次，沿用原始发生项身份。
- 支持最近一次调整撤销；任务已有后续变更时拒绝覆盖。
- 已在模拟器验证底部拖动 60→90 分钟、保存和撤销；整块长按拖动、跨列和边缘自动滚动未完成全量验收，边缘自动滚动尚未实现。
- 修复冲突检查忽略单次改期、ICS 导出错误地使用截止而不是计划时间的问题。

### ICS

- 支持 FREQ 的 DAILY/WEEKLY/MONTHLY/YEARLY、INTERVAL、COUNT 或 UNTIL、每周 BYDAY、EXDATE、RECURRENCE-ID 单次调课与取消。
- 按 UID 组合主事件和例外，主系列或例外无法可靠理解时整组不导入并报告。
- 不支持 RDATE、DURATION、BYSETPOS、非周一 WKST、RECURRENCE-ID RANGE、复杂月规则、月末/闰日跳过语义和任意时区。
- 重复主事件的月末日期大于 28 或年度闰日被明确拒绝，避免把 RFC 跳过语义误改成应用的月末补齐。
- 同 UID 再次导入保留本机版本，尚无来源自动更新、合并冲突界面。
- 日历导出仍为未来 30 天快照；备份格式升级到 **6**，读取 3/4/5/6，包含发生项例外和逻辑提醒，未包含设置或密钥。

## 0.7 这轮增加的行为

### 智能输入

入口：底部记一件事 → 一句话识别，或设置 → 语音、自然语言与 AI 配置。

- 独立 SmartEntry 组件；支持多行、分号、句号、另外拆分，最多 20 条。
- 离线补充中文数字时刻、上午/下午/晚上、半点、一个小时/半小时；非法日期时间拒绝；无法识别的语义保留原文而不伪造字段。
- 草稿预览展示日期、时间、时长、优先级、地点、备注及解释；可选择保存或打开单条编辑器。打开编辑器时原文仍保留，可再次识别；尚无原位多草稿逐字段编辑器。
- 保存前无业务数据写入；选中草稿事务保存；busy 防止重复点击。
- `DraftService.decode` 对模型 JSON、条数、日期、时间、长度、时长和优先级做程序校验。

### 云端 AI

- `AiClient` 对接用户填写的完整 HTTPS Chat Completions 地址与模型。
- 只有点击“发送给 AI 识别”才发送本次文字、当前日期和时区；不上传已有任务。
- 网络请求可取消，有连接/读取超时，拒绝异常 HTTP、非法 JSON 和超长响应。
- `AiSecretStore` 使用 AssetStoreKit；普通 Preferences 仅存地址和模型，密钥不进源码、普通配置、任务备份或日志。
- 尚未提供真实 AI 凭据，所以只完成接口编译、响应校验测试和无密钥失败路径；没有宣称真实云端端到端成功。
- 当前 AI JSON 不直接表达复杂重复/截止/提醒；这些信息要求保留在备注并手动确认编辑。多 provider、连接测试按钮、完整结构化 schema 仍待补齐。

### 原生语音

- CoreSpeechKit speechRecognizer，zh-CN offline 模式；AudioKit 采集 16 kHz、单声道、16 bit PCM，按 640 字节帧送入识别。
- 点击语音按钮后申请麦克风权限；支持结束、取消、超时；页面销毁和应用切后台释放录音与引擎。
- 识别文本进入可编辑输入框，不直接创建任务。
- 模拟器实测拒绝麦克风后显示失败原因且文字输入仍可用；本轮没有采集用户音频，也没有完成真机中文识别验收。

### 系统提醒

- 编辑器可选安排前／截止前及提前 0/5/10/30/60 分钟；日期事项的安排提醒使用 09:00。
- ReminderPlanService 按实际发生项生成未来 7 天意图，跳过已完成/跳过记录，改期沿用原 key。
- ReminderService 使用真实后台代理提醒 API，Preferences journal 记录 pending/registered/failed 状态。
- 用 getAllValidReminders 对账恢复系统 ID；先取消过期或变化的旧登记，再发布缺失项；独立、递增的 notificationId 避免覆盖。
- 保存任务成功与登记成功分开。注册失败不会回滚业务任务，也不会显示“提醒已设置”。
- 每次打开、修改数据时续约未来 7 天，应用侧最多尝试 50 条；系统实际配额和权益可能更少。长期不打开不会持续续约，不能依赖应用关闭后自己的定时器。
- 原生实测：通知授权成功，对账可调用；实际发布返回 **1700002**，界面保留失败状态。因此**后台提醒触发尚未验收成功**，不能拿适配器替身测试充当真机结果。
- 代码已接点击提醒的任务/发生项定位；真实通知跳转、锁屏、重启、进程退出后的触发需要可登记的设备进一步验收。
- 官方错误码参考：https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-reminderagentmanager 。本机 SDK publishReminder 声明也标明 1700002 为数量限制；不推断本设备为何配额不足。

### 辅助排程

- 设置中打开“为空闲时间生成排程建议”。当前使用确定性本地算法，不冒称 AI 已读取任务或自动规划。
- 只处理收集箱，优先级与创建顺序，最多 20 项；未来 7 天 09:00–21:00，15 分钟网格。
- 保留固定事件、已有安排、截止与优先级，找不到空档明确列出。
- 采用前比较完整任务和发生项快照，变化则拒绝；事务采用，可撤销最近一次；重新计算会清除旧撤销入口。
- 工作时段自定义、单条采用、AI 提议排序和远期规划未完成。
